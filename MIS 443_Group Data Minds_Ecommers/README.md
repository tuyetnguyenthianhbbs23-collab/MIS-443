# Project Description

This project was completed as part of the MIS443 Business Data Management course. The objective is to recreate the E-Commerce database from SQL Practice Online using PostgreSQL and pgAdmin.

The project includes database creation, table relationships, CSV data preparation, data insertion, and SQL solutions for all 30 practice questions.

# How to Run the Project

1. Open PostgreSQL and pgAdmin.
2. Execute **01_create_database.sql**.
3. Execute **02_create_tables_relationships.sql**.
4. Execute **03_insert_data.sql**.
5. Execute **04_questions_01_30.sql**.
6. Verify that all 30 SQL queries execute successfully.
